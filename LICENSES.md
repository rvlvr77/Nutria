# Licencias y atribuciones de datos

## USDA FoodData Central
Datos de dominio público (CC0 1.0 Universal). Atribución requerida en NutriAI:
**"FoodData Central, USDA"** — se muestra en la UI y en cada PDF exportado.
https://fdc.nal.usda.gov/

## SMAE — Sistema Mexicano de Alimentos Equivalentes
El SMAE es una obra editorial con derechos reservados (Pérez Lizaur A.B., Palacios González B.,
Castro Becerra A.L., Flores Galicia I., *Sistema Mexicano de Alimentos Equivalentes*, 4ª ed.,
Fomento de Nutrición y Salud A.C.).

- **Modo demo / MVP / uso educativo:** se usa un dataset reducido con atribución explícita.
- **Uso comercial:** requiere licencia del editor antes de distribuir el dataset o la app.

Este repositorio **no** debe publicarse con el dataset SMAE completo sin dicha licencia.
